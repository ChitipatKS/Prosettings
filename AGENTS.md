# Font Usage Rules
- Use Sans-serif (`font-sans`/`Inter`) for all standard UI labels, headers, descriptions, navigation elements, and normal text (e.g., "MOUSE SETTINGS", "DPI", "SENSITIVITY", "Razer Deathadder V4 Pro Black").
- Use Monospace (`font-mono`/`JetBrains Mono`) specifically for raw settings values, numbers, and data metrics (e.g., "400", "0.520", "1000", "1920x1080", "1"). This ensures clean spacing, alignment, and a technical database aesthetic.
